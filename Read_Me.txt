# Read_Me — ручной запуск бота Kiuha (@kiuhabot)

Бот: текст → ответ нейросети (Ollama) → голосовой ответ голосом друга (XTTS v2).

## Что должно быть запущено перед стартом бота

1. **VPN Happ** (без него Telegram не отвечает)
   - Открыть `C:\Program Files\FlyFrogLLC\Happ\Happ.exe`
   - Убедиться, что туннель `happ-xray` активен

2. **Ollama** (нейросеть)
   - Обычно запускается сама с Windows
   - Проверка: открыть в браузере `http://localhost:11434` — должна появиться надпись `Ollama is running`
   - Если не открылась: запустить `D:\Ollama\ollama.exe` (или ярлык Ollama в меню Пуск)

## Запуск бота

**Способ 1 (простой):**
Открыть папку `D:\Python\projects` и запустить двойным кликом **`run_bot.bat`**

**Способ 2 (через Планировщик задач):**
Нажать Win+R → ввести `taskschd.msc` → найти задачу **KiuhaBot** → «Выполнить»

**Способ 3 (вручную через командную строку):**
Открыть Win+R → `cmd` → выполнить:
```
cd /d D:\Python\projects
D:\Python\python.exe bot.py
```

## Как понять, что бот работает

- В чате с `@kiuhabot` отправить `/start` → должен ответить: «Бот на голосе друга включен»
- Отправить любое текстовое сообщение → должен прийти голосовой ответ

## Остановить бота

Закрыть окно, где он запущен (чёрное окно cmd), либо:
```
taskkill /f /im python.exe
```

## Возможные проблемы

| Проблема | Решение |
|---|---|
| Бот не отвечает вообще | Проверить VPN Happ |
| «Ошибка нейронки: …» в голосе | Проверить, что Ollama запущена |
| Медленно отвечает | Нейросеть грузится впервые, подождать |
| Окно закрылось сразу | Ошибка в `bot_run.log` — смотреть последнюю строку |

## Файлы

- `bot.py` — сам бот (здесь настройки: токен, модель, голос)
- `run_bot.bat` — запускатор
- `friend.wav` — эталон голоса друга (30 сек, для озвучки)
- `bot_run.log` — лог запуска (сюда пишутся ошибки)

## Настройки в bot.py (если нужно поменять)

- **Токен бота** — строка `Application.builder().token("...")`
- **Модель нейросети** — строка `MODEL = "..."`
- **Голос** — параметр `speaker_wav="friend.wav"` в функции `speak`
