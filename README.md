# Голосовой помощник Киюхе

Киюхе — голосовой помощник, который понимает речь пользователя, выполняет команды и отвечает голосом. Проект предназначен для людей, которым удобнее управлять устройствами и искать информацию голосом, а не вручную. Он экономит время на рутинных задачах: узнать погоду, поставить напоминание, найти информацию, управлять приложениями.

## Технологический стек
- Язык: Python
- Фреймворк: FastAPI
- База данных: PostgreSQL
- Инструменты: Git, GitHub
